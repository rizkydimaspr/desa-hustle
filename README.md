# Desa Hustle

Website interaktif desa 3D dari seri Desa Hustle (@hustlestory.id). Pengunjung masuk dengan username sosmed, membuat karakter, lalu jalan-jalan di desa. Ilustrasi: cerita fiktif.

- `index.html`: halaman lengkap (dibangun dari sumber di proyek Hustle Story).
- `three.min.js`: Three.js r160.

Data pengunjung dikirim ke Google Sheet milik Hustle Story lewat Google Apps Script.
